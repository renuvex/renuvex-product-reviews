# Competitor Insights

> Patterns / strategies / lessons across competitors that should inform our roadmap.

## Positioning
- Loox/Yotpo/Okendo are **not** ikas-native. We win on integration depth (auto-install, native scope, ikas-aware UX) — Judge.me's affordable broad-feature model is the closest analog and the right benchmark.
- Trojan-horse strategy: ikas merchants prefer ikas-native apps because of seamless install, single billing, and Turkish-language UX.

## Highest-leverage features (cost-vs-impact)
1. **Rich snippets** — single-day implementation, big SEO/CTR win for merchants. **First.**
2. **Review-request email** — bigger lift but compounds review volume. Required for parity.
3. **CSV import** — makes switching from Judge.me/Loox painless. Acquisition lever.
4. **Verified buyer badge** — we have ikas order API access; this is a moat we can build cheaply.
5. **Photo + email coupon combo** — pattern from Loox: "submit a photo, get a discount code". Pairs well with ikas discount API.

## UI patterns that win
- Live preview side-by-side with settings panel (we already have this)
- Templated quick-styles ("Minimal", "Classic", "Modern") — preset bundles of settings
- Star summary as the headline element
- Photos-first row at top of reviews

## What to avoid
- Yotpo-style bloat — keep onboarding simple
- Judge.me-style dense settings UI — group into tabs/accordions
