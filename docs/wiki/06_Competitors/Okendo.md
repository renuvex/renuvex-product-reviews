# Okendo

## Summary
Premium-feel, mid-market reviews + UGC. Polished theme integrations. Strong on attribute reviews ("size", "fit") and customer profile.

## Strengths to learn from
- Attribute / aspect-based reviews ("Runs small / true to size / runs large")
- Customer profile pages
- Premium-looking widget defaults — sets the bar for UI polish

## Notes for our app
- Aspect-based review questions are a useful differentiator vs Judge.me's flatter form
- Out-of-the-box UI polish matters more than feature breadth for first impression
